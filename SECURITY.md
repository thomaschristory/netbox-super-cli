# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Do not open a public issue. Use the private vulnerability reporting of GitHub:
[Report a vulnerability](https://github.com/thomaschristory/netbox-super-cli/security/advisories/new)
(**Security > Report a vulnerability** on the repository). Only the maintainer sees the report.
The maintainer replies, fixes the problem, and publishes an advisory with the fix.
